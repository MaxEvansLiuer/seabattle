# 局域网海战棋

一个由本机 Node 服务托管的双人浏览器海战棋。房间只保存在服务进程内；房主创建房间后，将 6 位房间码分享给同一 Wi-Fi / 局域网中的另一位玩家。

## 启动

需要 Node.js 18 或更新版本，不需要安装第三方依赖。

```sh
npm start
```

服务默认监听 `0.0.0.0:3000`。房主和加入者都在浏览器访问 `http://本机局域网地址:3000`。macOS 可在「系统设置 → Wi-Fi → 详细信息」查看本机 IP；Windows 可运行 `ipconfig` 查看 IPv4 地址。若端口被占用，可以用 `PORT=3001 npm start` 换端口。

## 游戏规则

- 棋盘为 10×10；两人各自摆放航母（5 格）、战列舰（4 格）、巡洋舰（3 格）、潜艇（3 格）、驱逐舰（2 格）。舰船不可重叠或出界。
- 双方舰队提交后由服务器决定先手。玩家轮流攻击一个未攻击过的格子；服务器判断命中、未命中、击沉和胜负。
- 浏览器只会收到自己的舰位及公开战况，不会收到对手未被发现的舰位。
- 房间和对局只存在于服务进程内；停止或重启服务会清空房间。浏览器会记住当前房间凭据，服务重启后需要重新创建或加入。

## 检查

```sh
npm test
```

手工联机验收：在两台连接同一局域网的设备上打开上述地址，创建并加入房间，完成布舰和整局对战。

# 局域网海战棋

一个由本机 Node 服务托管的双人浏览器海战棋。房间只保存在服务进程内；房主创建房间后，将 6 位房间码分享给同一 Wi-Fi / 局域网中的另一位玩家。

## 启动

需要 Node.js 18 或更新版本，不需要安装第三方依赖。

```sh
npm start
```

服务默认监听 `0.0.0.0:3000`，也就是接受本机各网络接口的连接。房主和加入者都在浏览器访问 `http://本机局域网地址:3000`。macOS 可在「系统设置 → Wi-Fi → 详细信息」查看本机 IP；Windows 可运行 `ipconfig` 查看 IPv4 地址。两台设备需连接到彼此可达的同一局域网；如果电脑防火墙拦截连接，需要允许 Node 服务接收连接。

端口和监听地址可通过 `PORT`、`HOST` 环境变量调整：

```sh
PORT=3001 npm start
HOST=127.0.0.1 npm start
```

第一条示例会使用 3001 端口；第二条只允许本机访问，不适合其他局域网设备连接。启动后，局域网玩家应使用运行服务的电脑 IP 和实际端口。

## 游戏规则

- 棋盘为 10×10；两人各自摆放航母（5 格）、战列舰（4 格）、巡洋舰（3 格）、潜艇（3 格）、驱逐舰（2 格）。舰船不可重叠或出界。
- 双方舰队提交后由房主（创建房间的玩家）先手。玩家轮流攻击一个未攻击过的格子；服务器判断命中、未命中、击沉和胜负。
- 浏览器只会收到自己的舰位及公开战况，不会收到对手未被发现的舰位。

## 对局流程

1. 房主输入昵称并创建房间，把页面显示的 6 位房间码发给另一位玩家。
2. 对方在同一局域网打开服务地址，输入昵称和房间码加入。每个房间只容纳两名玩家；第二名玩家加入后进入布舰阶段。
3. 双方依次摆放 5 艘舰船并提交。舰船不能重叠或超出 10×10 棋盘。双方完成后开始交替攻击，直到一方舰队全部被击沉。

## 隐私与限制

- 房间和对局状态只保存在运行中的服务进程内；停止或重启服务会清空所有房间，玩家需要重新创建或加入。
- 浏览器会把当前房间码和玩家凭据保存在该浏览器的 `localStorage`，以便重新打开页面时尝试恢复房间。清除该站点的浏览器数据会移除这些凭据；服务重启后凭据也无法恢复已清空的房间。
- 房间码用于加入等待中的房间，玩家凭据用于读取和操作对应玩家状态。只把房间码分享给预期的对手；不要把玩家凭据分享给他人。
- 服务使用普通 HTTP，并未实现账号系统或网络加密。请只在可信任的局域网中使用。

## 检查

```sh
npm test
```

自动测试覆盖房间隐私、舰船重叠和越界校验、轮流攻击、命中/击沉/胜负，以及 HTTP 创建房间、加入、布舰、开局和攻击流程。

手工联机验收：

1. 运行 `npm start`，确认终端显示服务启动信息。
2. 在运行服务的电脑上访问 `http://127.0.0.1:3000`；再让同一局域网的另一台设备访问 `http://本机局域网地址:3000`。
3. 一边创建房间，另一边用房间码加入；两边分别摆好舰队，确认进入对战。
4. 双方交替攻击，确认能看到命中、未命中和击沉结果，并在舰队全部被击沉后显示胜者。
